# Falai Bot

Bot automatizado para responder pesquisas no Falai.io usando Selenium.

## Como usar

1. Instalar Python 3.10+
2. Instalar dependencias:
   ```bash
   pip install -r requirements.txt
   ```
3. Editar `URL` no `bot.py` com o link da pesquisa
4. Rodar:
   ```bash
   python bot.py
   ```

## Requisitos

- Python 3.10+
- Chrome instalado
- pip
